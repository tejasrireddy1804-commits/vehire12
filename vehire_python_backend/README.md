
# VeHire - Python Backend Version

This version keeps the same frontend UI but converts the backend into Python using Flask.

## Features
- Flask backend
- REST API endpoints
- Health check API
- Login API
- AI Analysis API
- Same frontend UI preserved

## Run the Project

### 1. Install dependencies
pip install -r requirements.txt

### 2. Run backend
python app.py

### 3. Open browser
http://127.0.0.1:5000
