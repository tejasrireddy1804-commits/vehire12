# VeHire — AI Powered Video Resume Platform 🎥🤖

VeHire is an AI-driven hiring platform where candidates upload **video resumes** and recruiters can instantly evaluate communication skills, confidence, technical abilities, and job fit using automated AI analysis.

This MVP (Minimum Viable Product) demonstrates:

* AI-based video resume analysis
* Candidate skill extraction
* Job matching system
* Recruiter dashboard
* AI coding test evaluation
* AI interview scoring
* Modern responsive UI
